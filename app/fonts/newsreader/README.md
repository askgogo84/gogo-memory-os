# Newsreader

Official Google Fonts Latin WOFF2 files, downloaded on 2026-10-07:

- Regular: https://fonts.gstatic.com/s/newsreader/v26/cY9VfjOCX1hbuyalUrK49dLac06G1ZGsZBtoBAbNJYQ.woff2
- Italic: https://fonts.gstatic.com/s/newsreader/v26/cY9XfjOCX1hbuyalUrK439vogqC9yFZCYg7oRZaLFYYzbA.woff2

Both files contain the variable weight axis 200–800 at optical size 16pt.
The layout uses weights 300–600, matching the previous Google font configuration.
They are loaded with `next/font/local` so Newsreader does not require a Google
Fonts request during production builds. The existing CSS variable is preserved.
