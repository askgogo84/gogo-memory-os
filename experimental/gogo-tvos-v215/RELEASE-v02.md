# Gogo TV companion release and acceptance

Use the [companion runbook](README.md) for the current build, pairing, release signing, installation, and rollback instructions. The scoped TV credential is distinct from the mobile session. Use the checked-out branch’s Windows build wrapper or the shared companion build.

A companion signed with a different key cannot be updated in place. Build with the existing companion signer where available. Keep the Gadgetcue launcher, its Home remapping service, and Couch TV installed during companion updates.
