# AskGogo shared browser capability

The browser is a product-wide capability, not a shopping-specific integration. A user can give AskGogo a supported website task through WhatsApp or the dashboard. The backend keeps one owner-scoped task, opens the website in an isolated browser, records what it actually observed, and carries out only actions allowed by the task's mode and current permissions.

When a website needs a human step, AskGogo pauses that same task and offers **Take control**. The link opens a view into the same virtual browser in the user's browser. The provider session remains in the isolated browser; it does not move into the user's local Chrome profile. The user completes the human step there, returns control, and AskGogo resumes the saved task after checking current permissions and, for consequential actions, the specific approval and outcome. A stopped temporary browser can be restored on the same task only when the saved read is safe to retry. A restored browser is a fresh provider session, so choices made only in the stopped session may need to be repeated.

This contract applies across shopping, food, grocery, travel, and other website tasks. It does not imply that every site will load, allow automation, reveal the required evidence, or permit an action. AskGogo reports provider blocks and missing evidence as incomplete. It must not infer a price, stock, delivery total, booking, or successful submission from a browser screenshot or an unverified model answer.

Acceptance for each website journey: (1) the original task ID survives a handoff and browser restoration, (2) the user can open Take control on their device, (3) the human step is completed without secrets in chat, (4) return/resume does not repeat a consequential action, (5) the final answer cites the actual provider page, product or service, location, time, and relevant delivery/fee evidence, or names the precise blocker. Test each provider independently rather than declaring the shared browser universally successful after one site works.
