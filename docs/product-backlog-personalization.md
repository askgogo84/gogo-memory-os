# AskGogo dashboard personalization backlog

Captured from product review of Memorae on 2 Sep 2026. Do not implement before the currently active core backlog unless explicitly reprioritized.

## 1. Direct dashboard chat
Create a full web chat surface inside the AskGogo dashboard so users can talk to Gogo without opening WhatsApp. It must use the same AskGogo memory, reminders, calendar, lists, tasks, travel, documents and other product capabilities as WhatsApp, and conversations/actions should stay in sync across both surfaces.

UX direction:
- A calm full-width chat room, not a generic support widget.
- Gogo character present in the scene.
- Desktop-first comfort while remaining mobile responsive.
- Show conversation history from the same AskGogo identity.
- Support attachments, voice, documents/images and actions where technically safe.
- Never create a separate siloed web memory.

## 2. Personality
Let users choose how Gogo speaks. Initial modes can include:
- Calm companion
- Sharp professional
- Straight-talking coach
- Quiet minimalist

Tone should affect copy style, not product truth, safety behavior or action semantics.

## 3. Character personalization
Use the existing AskGogo character/logo more intelligently across the dashboard. Possible later extensions:
- unlocked looks/accessories
- subtle contextual poses
- seasonal or milestone cosmetics
- no visual clutter in core task flows

## 4. Comfort/drink personalization
Create an optional light personalization detail inspired by the idea of a 'coffee' room, but make it original to AskGogo. Let users pick a comfort drink or ritual (coffee, tea, matcha, water, hot chocolate, etc.) and reflect it visually in the chat/quiet-space scene. This should remain decorative and never affect core functionality.

## 5. Learn with Gogo
Coordinate with issue #6 / Master Gogo educational videos so contextual tutorials can appear inside the direct chat and personalization areas after launch.
