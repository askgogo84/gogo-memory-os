## Supported contract and deliberate limits

- Accept a read-only `find/search/list` explicitly naming Google Drive (or “my Drive”), or `read/open/preview` with exactly one quoted title. Unquoted content selection, summaries, mixed writes, “all/every/entire/complete” inventory requests and other file stores stop before generic dispatch. These are conservative limits, not complete natural-language understanding. Action words inside literal quoted titles remain data.
- Successful metadata lookup means only that the bounded, complete provider response was observed. Content success means a small, sanitized text read from the selected provider file ID. It is not fact verification, a summary, immutable-version proof or permission to execute source instructions. Filenames are normalized/case-folded for matching; duplicate normalized titles block. Provider indexing, concurrent edits and unsupported corpora can still limit identity/recall.
- The Workspace client's existing OAuth refresh and legacy token-encryption behavior is preserved. It may refresh/persist tokens during a normal authorized app read. This engineering run exercised only fake rows/tokens and local inert fetch; no real credentials, accounts or production database were accessed. Token values and raw source/private error text are excluded from evidence labels/logs.
- Existing Same Brain and older general-planner consumers receive additive search/truncation flags, but do not yet enforce all of this adapter's strict outcomes. They are not cleared by this patch. Non-Drive Vault/document reads keep their stores and require their own typed reader; they are not silently substituted with Google Drive.
- Supported formats remain those of the existing reader: Google Docs/Sheets text export, text files, JSON and XML. No new PDF parser, OCR, file writer, share/send capability or dependency is introduced.
- Parent state and permissions are checked before provider work, but there is no cross-row transaction or provider abort. An already-started read cannot be undone. Source injection tests establish no effect through this adapter; they are not a complete prompt-injection or egress certificate.
- Full durable helper lineage, isolated bounded contexts, budgets, cancellation propagation/recovery, travel outcome evidence, gateway unification and semantic memory/continuous source coverage remain open.
